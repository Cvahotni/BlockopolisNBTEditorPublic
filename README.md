# BlockopolisNBTEditorPublic
A small application written in C++ designed for quick editing of Blockopolis related NBT files, with public source code.

# Installation
- Right now you'll need to build this yourself, since I haven't made any public releases yet.
- You'll need to setup wxWidgets on your target system before building, please see tutorials online on how to do so.
- You may also need to install dependencies for your target system to properly install and setup wxWidgets.
- Some tutorials I found that may help from YouTube:
- https://www.youtube.com/watch?v=Z0TDnnlyscM
- https://www.youtube.com/watch?v=FOIbK4bJKS8

# Building
- Clone the repository to your folder
- Ensure Premake, CMake, and any other libraries are properly setup on your system, executable have been provided for backup purposes.
- Run in your terminal, i.e ./premake gmake (or vs2022, etc)
- Open with your desired IDE, in this case I use vscode, and run the build and launch process, or you can run make --jobs=2 in your terminal enviroment.
